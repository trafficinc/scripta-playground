A quick guide to Scripta
Start a script
<?scr
$name = "world";
echo "Hello, " . $name . "!\n";
Variables start with $. Use . to join strings and ; to end statements.
Make something reusable
function greet($name: string): string {
    return "Hello, " . $name;
}
echo greet("Scripta");
Types follow parameter names. Compare values with === and !==.
Keep moving
for ($i = 1; $i <= 5; $i += 1) {
    echo str($i) . "\n";
}
Convert numbers with str() when joining them to strings.
About this session
The playground runs only on your computer. Each run uses a fresh temporary folder and has no interactive input. Output appears when execution finishes.
Scripts can access files, processes, and the network with your account’s permissions. Only run code you trust. Use Quit session to stop the local server.
